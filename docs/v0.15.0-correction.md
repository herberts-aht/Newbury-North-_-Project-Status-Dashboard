# v0.15.0 correction

This patch is based on the full current project ZIP captured before commit.

It makes two corrections only:

1. `.github/workflows/main.yml` now includes `api_location: api` so Azure Static Web Apps deploys the managed Functions API.
2. `api/src/functions/projectControl.js` accepts the environment-variable names already configured in Azure:
   - `AZURE_TENANT_ID`
   - `AZURE_CLIENT_ID`
   - `AZURE_CLIENT_SECRET`
   - `SHAREPOINT_SITE_URL`
   - `SHAREPOINT_ACCESS_LIST`

The API remains backward-compatible with the originally documented names.

No existing dashboard UI files need to be replaced by this correction patch.
